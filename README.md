# Blastyard

The backyard blast party game for one phone: up to four players on a single device laid flat on the table, smart bots, a challenge campaign and a daily challenge. Free, offline, no ads. For iOS and Android (landscape).

- Plan (Hungarian): [docs/PLAN.md](docs/PLAN.md)
- Tasks / status: [docs/TASKS.md](docs/TASKS.md)
- Contributor guide: [CLAUDE.md](CLAUDE.md)

Stack: Vite · TypeScript · PixiJS v8 · Preact · Capacitor 8 · Vitest · Playwright.
